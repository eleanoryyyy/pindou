# 拼豆系统（个人豆仓）

做给自己用的拼豆库存与图纸工具。在电脑浏览器里本地打开就能用，数据保存在本机 IndexedDB，不用登录，也没有后端。

## 功能

- **库存与多豆仓**
  - 可以建多套豆仓，按色号记账。
  - 支持搜索和按色系筛选。
  - 入库可以单条录入、批量录入，或者套用套装模板。
  - 出入库都有流水，修改或删除流水后，库存会跟着更新。
- **阈值补豆**：给色号设好阈值后，库存一旦低于或等于阈值，就会在库存页和补豆清单里提醒。
- **开拼前检查与出库**
  - 拼之前先检查一张图纸需要的豆子够不够，缺哪些色号会列出来。
  - 拼完后按用量一键出库。库存不够时整单拦下，不会出库。
  - 出库可以撤销。
- **图纸识别**
  - 上传已有的 JPG 或 PNG 图纸后，能自动定位网格，也可以手动框选，再统计每种颜色的用量。
  - 可以粘贴图纸上的图例来校对。
- **拆板与合板**：按常见豆板规格把大图切成小图，也能把几张小图合回一张大图。
- **高亮跟拼**
  - 点一个色号，这个颜色的格子会高亮，其余的变暗。
  - 可以标记已经拼完的色号，也可以进入专注模式。
  - 进行中的作品可以记录进度，拼完后放进作品集。
- **JSON 备份**：在设置页导出或导入。

## 快速开始

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev     # 默认地址 http://127.0.0.1:5173
npm run build   # 打包
```

## 识别小提示

识别图纸时，把图例粘到「图例校对」里会更准，格式例如 `A16 11、H7 140`，用顿号、逗号或换行分隔都行。不录图例的话，相近的颜色可能会认错，比如 H2 认成 H1。

## 色卡数据

内置 MARD 221 色和 COCO 291 色两套色卡，数据来自 [HansBug/pindou-color-data](https://github.com/HansBug/pindou-color-data)，按 MIT 许可使用，许可原文在 `src/data/palettes/LICENSE`。

## 技术栈

React、TypeScript、Vite，数据层用 Dexie（IndexedDB）。
